# 搜索记录：S0 校准到 S2 新体系（截至 2026-11-11）

本文按时间顺序记录高 κ 搜索里试过的每一条路：做了什么、得到什么数字、为什么继续或放弃。结论性内容在 [README](../README.md) 的“当前进展”里，设计和参数来源在 [DESIGN.md](../DESIGN.md)。每一步工具调用都有 JSON 记录，在 `runs/<run_id>/records/` 下，文中给出的 step id 可以直接对应到文件名。

`decided_by` 的约定：`agent` 指 Claude 在已批准的计划内自己做的选择，`human` 指用户在对话里批准过的门槛或方向。改方向、上 L1 或大计算量之前，都先报结构数和 GPU·h，等用户同意。

## 0. 总体漏斗和协议

每个生成批次走同一个漏斗：

1. 生成，按原胞原子数过滤；
2. DPA 弛豫：随机 P1 起点先粗弛豫，再对称化、去重，最后用 FixSymmetry 精弛豫；
3. E_hull 门槛：对照 MP2020 修正的 MP 凸包，0 ≤ E_hull ≤ 0.1 eV/atom；
4. 只留接近收敛的弛豫结果：没收敛的残余力 ≤ 5 meV/Å、残余应力 ≤ 0.5 GPa；
5. MP 新颖性：去掉 MP 里已有的结构；
6. L0：FC2、虚频门槛、Slack 估计；
7. 稳定结构里挑候选上 L1（3ph Wigner-RTA，κ_SRME 协议）。

## 1. S0 校准（`runs/s0-calibration/`）

- **κ_SRME 子集**：c-BN、w-AlN、3C-SiC、BAs 四个化合物上，三个模型相对 phononDB 的偏差都在 ±5.5 % 以内，SRME 0.028–0.040。移植的 κ 协议和 matbench-discovery 排行榜上同一模型的结果相差不超过 2.4 %。
- **L1 → L2**：LBTE 直接解让 c-BN 的 κ 提高 12–13 %，BAs 提高 89–90 %（约 2320 W/mK，实验约 1300）。只算 3ph 时 BAs 的高估是已知现象，需要 L3 的四声子散射修正。
- **未解决**：R3m-BNC₂ 的 FC4 拟合在 300 GB 内存下 OOM。
- **定下的“命中”基准**：c-BN（约 850 W/mK）和 BAs（约 1300 W/mK）。

## 2. S1 试跑（`runs/s1-trial/`）

7 个化学体系，每个体系让 MatterGen 生成 16 个，只保留小原胞：

- 112 个生成 → 原胞 ≤ 8 原子、去重、剔除 κ_SRME 测试化合物后 46 → 对称化 + 弛豫收敛 36 → L0 稳定 8。DPA 和 TECE 判出的稳定结构完全一致。
- **教训：生成结构必须先对称化再弛豫。** 直接按 κ_SRME 协议弛豫，大多数到 300 步上限都不收敛；先理想化对称性（symprec 0.1）再弛豫，收敛的多了很多。
- **教训：L0 之前要先卡 E_hull。** 8 个稳定结构全部在 MP 凸包以上 0.25–0.71 eV/atom，L1 κ 只有 10–64 W/mK。之后所有批次都在 L0 之前加了 E_hull ≤ 0.1 eV/atom 的门槛（用户 11-09 批准）。
- **PET-OAM-XL 退出 L1**：4 个结构跑满 24 h 仍未完成，只保留在 L0 委员会里。

10 个化学体系：Al–B–N、Al–C–N–Si、As–B–P、As–B、B–C–N、B–C–P、B–N、B–Sb、C–N–Si、C–N。共三批：b1、b2 只按化学体系条件生成（cs），b3 同时以 E_hull = 0.05 eV/atom 为条件（cseh），guidance 都是 2.0。

观察：

- **E_hull 条件没有提高命中率。** b3 通过 E_hull 的 38 个里有 19 个是单质；只看化合物，命中率约 2 %。
- **约一半输出是单质或子体系。** 这是 MatterGen `chemical_system` 条件的预期行为：它只保证不出现体系外的元素，不保证每种元素都出现（[issue #117](https://github.com/microsoft/mattergen/issues/117)）。
- 两个富氮结构的 E_hull 为负（B₃N₅ −0.085、BN₂ −0.037 eV/atom），L0 都有虚频，判为 MLIP 误差。
- **修了一个 bug**：体心晶胞的 q 网格原来按长度规则逐轴取，会破坏点群对称性。现在被对称操作联系起来的轴取同一个网格数（`symmetric_q_mesh`）。
- **跨批次重复很多**：18 个 L0 稳定结构去掉单质、跨批次去重后只剩 12 个。AlSiCN 的 sg 160 和 sg 8 两个版本原子位置只差 0.007 Å（RMS），Slack κ 却是 618 和 510–529 W/mK，说明 Slack 对微小的对称性破缺很敏感。
- **委员会 L0**：TECE 和 PET 都认为 AlSi₂C₂N-40f6 有虚频，DPA 认为稳定。其余结构三个模型的 Slack 排序一致。

## 4. 换生成方式：AIRSS 试点（11-10）

动机：MatterGen 在已探索的三元、四元体系里命中率低，而文献显示离子替换或原型枚举加 MLIP 预筛并不比扩散模型差（[Szymanski & Bartel, Mater. Horiz. 2025](https://pubs.rsc.org/en/content/articlelanding/2025/mh/d5mh00010f)）。

- 按四面体配位 / 8 电子规则枚举电荷平衡的化学计量，10 个体系共 52 个约化化学式。
- 用 AIRSS 0.9.3 的 `buildcell` 生成随机 P1 晶胞，参数 MINSEP 1.3 Å、SYMMOPS 1。
- 漏斗：粗弛豫 → 对称化 → 去重 → 精弛豫 → E_hull → 新颖性 → L0。
- **≤ 4 原子的试点**：390 → 去重 237 → E_hull ≤ 0.1 共 12 个（找回了 BN 和闪锌矿 BAs）→ MP 里没有的 6 个 → L0 稳定 3 个。
  - 一个是 AlSiCN sg 160，和 MatterGen 找到的 e67f 是同一个结构。
  - 另两个是 B₂AsP（sg 156 的 4e8c、sg 160 的 880e，Slack 约 290）。用户决定这两个不上 L1。
- step id：import `20261110T054702-import_structures-7da8f0` → … → L0 `20261110T064003-submit_mlip_fc2_descriptors-68b6d8`。
- **B–Sb 上 DPA 失效**：两个 BSb 结构弛豫后坍缩到 E_hull −210 和 −23 eV/atom，其余 BSb 全在 +0.25 以上。用户决定 B–Sb 的结果全部不采用。由此给 `compute_ehull` 加了 E_hull 下限：低于 −0.1 eV/atom 的结构记为 implausible，不进入输出集（commit dbbc8e3）。

### 小结：≤ 8 原子、这 10 个体系已经基本找全

AlSiCN sg 160 被 MatterGen、AIRSS、CSP 各找到一次，B₂AsP sg 156 被 AIRSS 和 CSP 各找到一次。三种原理完全不同的生成器反复收敛到同一批结构，L1 上限约 240 W/mK。所以 AIRSS 全量不再跑，改为换化学体系（用户 11-11 同意）。

## 6. S2：新化学体系（11-11，进行中）

### 选体系

高 κ 的判据是轻原子、强共价键、结构简单，或者大质量比带来的声学–光学能隙。查 MP 后调整了候选清单：

- **去掉 Al–Ga–N**：MP 里已有约 10 个有序合金接近凸包。AlN–GaN 几乎是理想固溶体，生成器只会找到更多排列方式，而有序合金的 κ 低于纯 AlN。
- **去掉 B–Ga–N**：凸包附近没有任何三元相，B 和 Ga 尺寸差很大。
- **最终 7 个体系**（用户 11-11 确认）：Be–O、Be–C、Be–C–N、Be–Si–N、B–Be–N、Al–Be–N，再加 Ga–N 二元。
  - Be–C–N 有 BeCN₂（sg 122，8 原子）。
  - Al–Be–N 在 MP 里一个三元结构都没有。
  - B–Be–N 也没有三元相。
- Be–Ge–N、Mg–Si–N 留作第二批。

### 生成：PyXtal 对称约束随机结构

**为什么不只按原子数放宽**：κ 主要由原胞原子数决定，因为每多一个原子就多 3 支光学支，Slack 公式里也有 κ ∝ n^(−2/3) 这一项。放宽原子数主要是为了覆盖更多化学计量比，以及惯用胞大、原胞小的高对称结构。所以条件设成“高对称性 + 原胞原子数上限”。

**设置**：

- PyXtal 1.1.5 的 `from_random`，限定 sg ≥ 75（四方及以上晶系），原胞 ≤ 12 原子。
- 化学计量按固定氧化态取电荷平衡：Be²⁺、O²⁻、C⁴⁻（BeCN₂ 里 C⁴⁺）、N³⁻、Si⁴⁺、B³⁺、Al³⁺、Ga³⁺。
- 生成时就要求最短原子间距 ≥ 1.2 Å。
- 用 Wyckoff 相容性检查枚举（组成, 空间群）组合，共 2395 个，其中 1899 个有自由参数。三元体系每个组合采样 3 个，二元体系 1 个。

**结果**：请求 4143 个，成功 4045 个，原胞平均 8.2 原子。

|---|---|---|
| Be–Si–N | 841 | 8.4 |
| Be–C–N | 814 | 8.3 |
| Ga–N | 507 | 6.8 |
| Be–O | 492 | 6.7 |
| Al–Be–N | 453 | 9.8 |
| B–Be–N | 441 | 9.7 |
| Be–C | 338 | 7.9 |

**计划的漏斗**：生成时已经带对称性，所以跳过粗弛豫，直接做 FixSymmetry 精弛豫（1000 步）以保持生成的空间群。之后接 E_hull（含 d_min 检查）→ 接近收敛 → 去重 → 新颖性 → L0（A100）。

- 按 CSP 的单位成本和原子数修正估算，约 20–25 GPU·h。
- **还没提交**，等用户确认计算量。
- 已知的取舍：sg ≥ 75 会漏掉 II-IV-N₂ 的正交基态。BeSiN₂、MgSiN₂ 的基态都是 sg 33。

## 7. 改成闭环：候选池 v1（11-11）

动机：到目前为止每一批都是单向漏斗，下游结果不回流。用户 11-11 决定改成“固定候选池 + 代理模型选样 + 回放对比”的闭环，PyXtal 那批（4045 个）不再提交。

- **E_hull 门槛的问题**：按缓存的 MP 凸包，金刚石在凸包以上 0.138 eV/atom，c-BN 0.077，BAs 0.080，B–C–N 三元最低 0.173，BC₂N 多型 0.54–0.99。“E_hull ≤ 0.1 且 MP 里没有”留下的基本只有四面体二元化合物的有序合金。闭环里 E_hull 改为和 κ 一起报告的属性，不再当硬门槛。
- **L1 实测单价**（DPA，25 个结构）：平均 0.69 GPU·h，中位 0.49；L0 约 0.01；L2 中位 0.87。
- **候选池**（`scripts/build_pool.py`，确定性生成，没有随机结构）：
  - `enum`：闪锌矿（2–8 原子的全部超胞）、纤锌矿（4、8 原子）、岩盐（2、4 原子）上的有序占位，按固定氧化态电荷平衡，每个子格最多两种元素；
  - `bcn`：同样的闪锌矿、纤锌矿超胞上 B/C/N 占所有位点，n(B) = n(N)；
  - `subst`：项目里 L0 稳定的结构和缓存的 MP 结构（E_hull ≤ 0.3、原胞 ≤ 8 原子）做同族元素替换；这些 MP 结构本身作为 `known` 放进池子。
  - 化学体系限制在 S1-main（去掉 B–Sb）和 S2 的 16 个体系内。
  - 占位先用母格超胞的空间群约化，再用近邻距离签名和 StructureMatcher 去重：75187（不限体系）→ 限体系后 16797 → **1209**。
  - 构成：enum 447、bcn 570、subst 135、known 57；969 个是 8 原子；B–C–N 占 605 个。

## 8. 经验汇总

1. **生成器的瓶颈不在“生成”而在“筛选”。** 三种生成器在 E_hull ≤ 0.1 上的命中率都是百分之几，而且收敛到同一批结构，说明这些体系的低能小原胞结构空间已经很小。
2. **MLIP 在生成结构上会坍缩。** 原子间距过小时 DPA 的排斥力不够，E_hull 可以低到 −36870 eV/atom。必须有三道防线：
   - 生成时的最短间距过滤（MINSEP）；
   - E_hull 下限；
   - 弛豫后的最短间距检查。
3. **Slack 估计只能当门槛。** 它对微小的对称性破缺很敏感，和 L1 的排序相关性也弱。
4. **κ 的上限由原胞原子数和元素决定。** 在 Al–Si–C–N 和 B–As–P 体系里 L1 约 240 W/mK 封顶，要更高只能换成更轻、键更强的体系。
5. **运维方面**：
   - runner 的状态更新会滞后，判断作业卡住前先看 `end_time`；
   - datalab 会惩罚频繁 SSH 的 IP，只能通过 DB 轮询；
   - 轻元素超胞要用 80 GB 显卡。
