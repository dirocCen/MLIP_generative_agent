## 关键证据位置与比较边界

- **R19**：本次详细表值据 [v1，Table 1](https://arxiv.org/html/2503.11568v1#S5.T1)：AlSiCN 为 mp-1227998、P3m1，E_hull=0.04，κ=(317,317,275)；B₆O 为 mp-1346，κ=(279,279,206)。它们是已知结构的性质证据，不是本项目发现；AlSiCN 的最终宽带隙资格仍须本项目计算。`MatterK` 的大规模标签主要是 MLIP+3ph-RTA，不是几十万条 DFT κ 真值。
- **R20**：Results 的生成筛选与 Discussion：10 万原始碳结构、34 个高 κ 多形体、8 个结构新；阈值为**任一方向** >800，不能和本项目建议的张量平均值直接比较。文中已有 QBC 主动学习，因此“用分歧挑 DFT”本身不是独有贡献。
- **R21**：[预印本](https://arxiv.org/html/2507.19799v1) 的 “Generating high-performance functional materials” 与 Methods：MatterSim-v1.0.0-5M 提供筛选 IFC，DFT 作核验；GeC 的 183/2.34 是其报告值，不代表我们已复算。期刊摘要可核实工作定位；上述方法细节以预印本版本为准。“high-κ dielectric”在同文另一任务中指高**介电常数**，不能误当成热导率。
- **R22**：[v4 §4.4 / Table 3](https://arxiv.org/html/2601.07742v4#S4.SS4)：0.446→0.307 是 Nequix-MP；PFT 的监督对象是 Hessian，不能给普通 E/F/S 微调套用这个名称。它的 no-cotrain 模型虽有更小 κ 误差，却有严重通用性质退化，必须同时检查遗忘。
- **R16**：本次机制/方法解读以公开 [v3](https://arxiv.org/html/2408.00755v3) 为依据；2026 正式发表已查证。其材料依赖的微调成功，不等于跨化学空间的小预算微调一定提高全 103 平均分。
- **R08 vs R04**：>2100 是 2025 实验报告，1400 是 2017 特定 3+4ph 理论结果。原文也承认新实验和既有理论间仍有待解释之处，不能把 1400 宣称成现已验证的普适绝对真值。

## 排除表的使用与尚未核实项

[phonondb_pbe_103_manifest.csv](phonondb_pbe_103_manifest.csv) 保存名称、化学式、原型空间群及每条 NIMS 数据/输入下载链接，来源是 D1 的 **2026-10-20 网页快照内容**。`prototype_spacegroup_number` 按标准原型映射（186/216/225），不是对原始结构运行 spglib 得到的结果。CSV 不包含 DFT 力常数、训练标签或 κ 值；正式计算时仍应下载 D2 的结构文件并核对哈希、原子坐标和计算口径。

逐行统计得到 **103 个唯一成分–原型键、70 个不同化学式、34 种元素**。有关轻元素体系的直接命中有 BN/BP/BAs/AlN/GaN/BeO/SiC 的两个原型；BSb 未命中。103 个结构条目不能误写为 103 个互异化学式。建议保守排除 70 化学式所有多形体；这样 B–N 组中的 1:1 BN 即使生成新原型，也只用于发现/对照，不可用来微调后再报告同成分“外推”。

尚未核实的是 MP/Alexandria 各建议体系的完整条目数与当前库外比例；没有执行账户 API 查询或全库下载，因此不提供虚构统计。新颖性还须包括完整数据库、已发表结构及各基础势预训练数据的匹配；S2 的“库外”与模型的“训练外”是两个标签。文献检索不是系统综述，结论只覆盖本任务的轻元素 3D 主线；未找到的实验/数值在正文明确标记。

检索渠道：出版社页面、arXiv 全文与补充材料、作者公开稿、官方 GitHub/NIMS/NIST；检索主题覆盖 Slack、BAs/BSb 选择规则、四声子、lone pair、2024–2026 uMLIP 热输运、generative crystal/κ、Hessian fine-tuning、MatterGen 条件。未登录、未购买付费全文，未提交表单，也未执行生成、DFT 或微调。
