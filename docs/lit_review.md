# 高 κ 材料的化学空间与项目定位

范围：常压、约 300 K 的 3D 体相晶体；κ 单位均为 W m⁻¹ K⁻¹。文献与证据位置另见[文献表](lit_review_references.md)。**建议主攻 B–C–N、Al–C–N–Si；“生成 + 势函数 + 主动学习 + κ”已有直接先例**，项目应检验可审查决策及针对性数据的价值。[R19] [R20] [R21]

## 1. 可用于筛选的判据

在声子气体近似下，κ 由模态热容、群速度和寿命共同决定。下列特征用于排序，不能替代 IFC2/IFC3 与输运计算。[R14] [R16]

| 判据 | 机制与边界 | 对生成/筛选的含义 |
|---|---|---|
| Slack：轻元素、强键/高 Debye 温度、小原胞、低非谐性 | 通常带来高声速和长寿命；质量项须与键刚度共同看，不能孤立套用 Slack 公式。[R01] | 优先 B/C/N/Si/Al 的致密网络；≤8 原子是成本与搜索先验，并非高 κ 定律 |
| acoustic–optical gap 与 acoustic bunching | 若最低光学频率高于两声学频率可达之和，a+a↔o 通道可被关闭；声学支聚束还能限制部分 a+a↔a 过程。BAs、BSb 是反例，说明重元素不必然低 κ。[R02] [R03] | 从实际色散计算相空间；有 gap 不能直接判高 κ |
| 质量比、共价性、配位 | 质量反差可拉开声学/光学支，也会降低部分群速度；强方向性键有利，但配位数本身没有单调规律。相同化学式不同原型仍可能有不同 κ。[R03] [R11] [R12] | 偏好 3D 连通的强键网络；四配位只作软先验，不排除其他配位 |
| 非谐性、孤对电子、无序 | stereochemically active lone pairs 可造成畸变和非谐；不能把所有含 N/O 的闭壳层材料都判为低 κ。随机占位、空位和同位素另增散射。[R05] [R06] [R10] | 区分有序晶体与真实无序陶瓷；检查软模、模态 Grüneisen 参数及散射率 |
| 四声子与 Normal 过程 | 三声子受限时，四声子相对贡献可很大；升温和强四阶非谐性也会增强其作用，gap 不是充分条件。BAs 的经典计算由 3ph 的 2200 降至 3+4ph 的 1400。[R04] | 发现候选补 MLIP-LBTE；无 IFC4 的结果标成“3ph 近似”，不能把 RTA 和四声子误差互相抵消当验证 |

**宽带隙交集**以 diamond、c-BN、AlN、BeO、SiC、GaN 所代表的共价/混合键空间为出发点；不是一般意义的“硬材料空间”。c-BN 的实测带隙约 6.2 eV；BAs 约 1.82 eV，不能因 κ 高就进入严格绝缘候选。[R06] [R09] [R10] [R12] [R32] 建议最终报告 `E_g ≥ 2 eV` 与 `≥3 eV` 两档；PBE 带隙用于初筛，边界候选需更高层级验证，带隙也不能替代电阻率。[D4] B–P/B–As 体系保留为热输运机制对照，不能整体视为宽带隙。

## 2. 已知高 κ 材料与基准成员

以下为与本项目相关的代表性清单，**不是所有高 κ 晶体的穷举表，也不是统一计算口径的排名**。RT 指原文 room temperature；≈ 表示量级或近室温值；“未摘数值”不表示没有计算。实验与计算的同位素、方向、RTA/LBTE 必须分别核对。

| 材料；空间群/原型 | 实验 κ（约 300 K） | 计算 κ / 方法 | κ_SRME-103 成员？ |
|---|---|---|---|
| C；Fd-3m #227，diamond | 高纯单晶可达 2400 [R34] | 有 DFT variational-LBTE；本次未摘数值 [R35] | 否 |
| Si；Fd-3m #227，diamond | ≈150；仅作校准 [R14] | DFT-BTE 与实验 RT 差 <5%；未摘精确值 [R14] | 否 |
| BN；F-43m #216，zincblende | 天然丰度 850–880；富集 >1600 [R06] | 天然丰度 3ph 约 940 [R03] | 是；另有 w-BN #186 |
| BAs；F-43m #216 | 2025 年报告 >2100 RT [R08] | 2200（3ph）；1400（3+4ph），为不同近似 [R04] | 是；另有 wurtzite |
| BP；F-43m #216 | 460 RT [R07] | 3ph 天然丰度约 580 [R36] | 是；另有 wurtzite |
| SiC；3C，F-43m #216 | >500 RT，高纯晶圆 [R09] | DFT 内禀值与实验相符；未摘数值 [R09] | 是；另有 **2H** #186 |
| SiC；6H，P6₃mc #186 | 490 @300 K [R13] [D3] | 有 DFT-BTE；未摘数值 [R15] | 否；**同空间群不代表同一原型/堆垛** |
| AlN；P6₃mc #186，wurtzite | 321 RT，厚外延层 [R10] | 约 320，DFT-BTE [R10] | 是；另有 zincblende |
| GaN；P6₃mc #186，wurtzite | ≈200 @300 K [R15] | 有 3ph-BTE；天然/富集须分开 [R12] [R15] | 是；另有 zincblende |
| BeO；P6₃mc #186，wurtzite | 高纯体相约 370 [R01] [R11] | DFT-BTE 与实验相符；未摘数值 [R11] | 是；另有 zincblende |
| B₆O；R-3m #166 | 本次未找到可核实的对应实验 κ | DFT-3ph：κxx=κyy=279，κzz=206 [R19] | 否；常见结构原胞 14 原子，超出主线预算 |

**成员已逐项核对官方 PBE 目录**：103 条 = 33 wurtzite + 33 zincblende + 37 rocksalt，只有 **70 个不同化学式**；不含 BSb、C、Si。[D1] [D2] 全部条目及 NIMS 原始数据链接已存为 [CSV](phonondb_pbe_103_manifest.csv)。本项目建议新增微调、回放与验证数据一律按这 70 个化学式保守排除，连同位移、rattle、MD 后代一起排除；原型核对再用结构匹配。基准条目可做流程检查，但不得用其 κ 标签挑超参数/选 checkpoint。预训练模型是否已见过相关母相需另披露，不能宣称整个模型“无泄漏”。

## 3. 已有筛选、uMLIP 与生成工作

| 工作 | 数据、方法与结果 | 本项目必须区分/吸取的部分 |
|---|---|---|
| Seko 2015；AAPL 2017 [R17] [R18] | 前者以 101 个 DFT 标签对 54,779 个数据库化合物做 Bayesian 筛选；后者自动化 IFC3+BTE | κ 自动化、主动选样已有先例；AAPL 是方法框架，不是新材料命中率证据 |
| Póta 2024/2026 [R16] | 103 个 PBE 条目；基础势 + Wigner/RTA、模态 SRME、MACE 微调 | 本项目指标与诊断的直接基线；103 条结构/化学空间有限 |
| Li 2025，MatterK [R19] | >50 万结构搜索；对 236,574 个动力学稳定结构用 MatterSim+3ph-RTA 算 κ，约 20 个候选补 DFT | 小原胞二元空间已大规模探索；金属和缺少高阶散射的高值不能直接转作绝缘发现 |
| **Guo 2025** [R20] | **CDVAE + Allegro/QBC 主动学习**；10 万碳结构筛出 34 个方向性 κ>800 的多形体，8 个结构新 | **最接近本项目的闭环先例**；换 MatterGen 或加 agent 不能单独构成科学新颖性 |
| **Cheng 2025/2026，CrysVCD** [R21] | 价态约束生成 + MatterSim/phono3py + DFT；展示 GeC，κ=183、带隙 2.34 eV | 已覆盖“化学先验 + 生成 + 高 κ + 带隙”；GeC 不在 MP-20 但已在完整 MP，说明训练集新颖≠材料新颖；细节据预印本 |
| Anam 2025；Al-Fahdi 2025/2026 [R23] [R24] | 前者在 OQMD 2,429 个结构比较六个势配置；后者用成键描述符/GNN 筛约 20 万结构，DFT 确认 13 个 κ>100 候选 | 力误差不能代替 IFC/κ 误差；成键筛选工作不是 uMLIP 直接输运计算 |
| Shen 2025；Minhas 2026 [R25] [R26] [R33] | 分别涉及 uMLIP 辅助低 κ 筛选、CrystaLLM 生成低 κ、微调 MatterSim/Wigner | “生成 + κ”和“微调 + κ”均非空白；低 κ 的指标/物理不能直接外推高 κ |
| **Koker 2026，PFT** [R22] | **直接监督能量 Hessian**，配合 upstream co-training；Nequix-MP κ_SRME 0.446→0.307 | 普通位移力微调不等于 PFT；预算相同的随机选样/分歧选样比较，才可检验本项目的数据效率 |

建议把研究问题写为：**相同 DFT 预算下，模型分歧与性质链诊断选样，比随机/固定规则选样能改善多少 κ？可审查 agent 的预算决策是否更好？** 用独立留出的候选报告力→IFC2→IFC3→κ，并报告不确定性与误差抵消。新增数据尽量同时覆盖单原子与成对位移；只有 IFC2 改进不能证明 IFC3 已准确。[R16] [R22] “新生成”本身不证明对基础势 OOD。[R21] [R27]

## 4. MatterGen 条件建议

下表**是基于文献的搜索假设与资源建议**，不是新候选的实测证据。配额指原始生成数：先每组 16 个检查有效率，再按表扩展，总计 2048；不保证去重后存活数。均标准化原胞后计数，全部在 ≤8 原子内；低对称结构保留一部分，防止简单晶体先验封死搜索。[R01] [R20]

| 优先级；体系；建议数 | 选择依据与已知探索程度 | 风险；原胞/空间群建议 |
|---|---|---|
| A；**B–C–N；640** | 强轻元素键；BC₂N 已有高 κ 预测及 MP 多形体，非空白体系。期待有序成键/堆垛变化；先关注 B:N≈1:1 的电子计数 [R19] | 已知部分高 κ 相 E_hull 很高，易分解为 C+BN；高压合成。4–8；不硬锁 SG |
| A；**Al–C–N–Si；512** | AlSiCN 已在 MP（mp-1227998），DFT κ≈275–317、E_hull≈0.04 eV/atom，是明确的四元锚点 [R19] | 原锚点重现不能算发现；新有序相是推测，四元凸包竞争相较多。4–8；不硬锁，保留三方结构 |
| B；**C–N–Si；384** | SiC 提供高 κ 参照，已有晶态 SiCN 预测，说明有结构空间；**尚无证据保证该体系普遍高 κ** [R09] [R28] | 已报道等原子比 SiCN 可为金属，须筛带隙；分相/分子状网络风险。4–8；不硬锁 |
| B；**Al–B–N；256** | BN/AlN 两端均高 κ，混合氮化物已有相平衡研究；有序排列可检验端元间插值先验 [R06] [R10] [R30] | 混合、畸变和分相风险；本次未找到可核实的该三元高 κ 数值。4–8；不硬锁 |
| C；**C–N；128** | 强共价 3D 碳氮框架已能合成回收，tI14-C₃N₄ 的原胞 7 原子可覆盖 [R29] | >100 GPa 合成条件；常压 E_hull 可能过不了阈值，不能放宽后仍称稳定。≤8；不硬锁 |
| 对照；**B–N；128** | c/w/h-BN 等已知原型与 MP 高 κ 多形体充分，适合作流程/重发现对照 [R06] [R19] | 新颖性较低；BN=1:1 的生成体不能进入本轮微调；筛除层状弱轴。2–8；不硬锁 |

**MP/Alexandria 的现状边界**：以上“已探索”依据论文/明确 MP 条目，未完成两库各体系全量统计，Alexandria 各行条目数与新结构占比均**未核实**。其数据库近期已大幅扩充，不能从 MP-20 或旧 sAlex 推断当前库外新颖性。[R21] [R31] S2 必须记录查询日期/版本，对完整 MP、Alexandria、MatterK 与已发表结构分别匹配，才可给候选贴“新”标签。

**降级项**：Be–O 留给校准（两个主原型均在 103 表，额外训练空间有限）；Al–N–O 暂不分配主线预算：常见 γ-AlON 是含空位/占位无序的大结构，≤8 原子不能代表它，不能用 AlN 的高 κ 替它背书。[R11] [R37] 不做纯 C 大规模生成，已有工作重叠高。[R20]

**条件可实现性与代理对照**：官方分别提供 `chemical_system`、`space_group`、`ml_bulk_modulus` checkpoint，但没有现成的“化学体系+空间群+体模量”联合权重；本轮用化学体系条件，SG 后筛，并检查生成后是否真正包含指定全部元素。[R27] [D5] 高体模量对照有意义，但只约束压缩响应；声速还依赖剪切模量/密度，寿命没有被约束。可另生成 128 个官方文档示例条件 `B=400 GPa` 的样本作探索对照；它的化学空间不同，**不能据此声称化学先验的因果增益**。更便宜的匹配对照是在同一批候选上比较按 B、声速/剪切模量、实际 κ 排序的效果；这些均为建议，不是文献最优阈值。[R19] [R27]
